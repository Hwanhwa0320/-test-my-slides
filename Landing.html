사례

청년정책 신청 절차 불편 찾기

01문제

신청 절차에서 신청자가 멈추는 지점과, 공고문과 근거 규정이 다른 조항이 정리되어 있지 않았습니다.

02한 일

  1. 신청 절차를 처음부터 끝까지 따라가며 막힌 곳 기록 → 문제 정의서
  2. 공고문을 근거 규정과 조항별로 대조 → 공고문 대조표
  3. 이용자 의견을 받아 반영 여부와 이유 정리 → 이용자 의견 반영표

03결과

  • 찾은 막힌 곳7곳
  • 찾은 틀린 조항2곳
  • 의견 받은 이용자5명
  • 남긴 산출물3건
  • 수행 기간입력 필요
일하는 태도

일하는 방식 3가지

  • 신청 절차를 직접 거친 뒤 문제를 적습니다

    확인 자료: 문제 정의서 (막힌 곳 7곳)

  • 조항마다 근거 규정을 붙여 확인합니다

    확인 자료: 공고문 대조표 (틀린 조항 2곳)

  • 반영하지 않은 의견도 이유를 적습니다

    확인 자료: 이용자 의견 반영표 (이용자 5명)
